- 발행: 서울특별시 빅데이터담당관 / 한국교통연구원 교통빅데이터 연구본부 / KT AI/BigData 사업본부

## 1. 개요

### 1.1 개발 배경
- 스마트도시 목표에 맞는 시민 이동 데이터 필요
- 생활인구 데이터 이후 공공/민간 활용 증가
- 통근·통학 시간 개선 등 삶의 질 향상을 위한 객관적 데이터 확보 필요
- 핵심 질문: **언제, 어디서 어디로, 어떤 사람들이, 얼마나 이동했고, 소요시간은 얼마였나?**

### 1.2 기대효과 / 활용처
- 통근시간을 계량화된 행복 가치 측정도구로 활용
- 대중교통 수요예측, 청년주택 입지, 삶의 질 연구 등
- 다른 데이터와 융합해 새로운 가치 창출
- 서울시(정책·시민서비스), 교통연구원(정책연계), 통신사(기술 완성도·영업)

### 1.3 개발 목적
- 통근·통학 시민 이동 데이터 융합 제작
- 민관공동 빅데이터 플랫폼 시범사업
- 시민공개를 통한 스타트업 지원 등 데이터경제 활성화

### 1.4 데이터 정의
> **'특정 시점', '특정 지역 간'에 '이동'하는 서울의 모든 인구**
> (서울 안에서 이동하거나, 서울 외부에서 서울로 오고 간 사람들의 이동)

- 특정 시점: 일별, 시간대별
- 특정 지역(출발지/목적지 기준):
  - 서울: 교통폴리곤
  - 수도권: 읍면동
  - 기타: 시군구 단위

### 1.5 데이터 소스
- 서울시 보유 공공 빅데이터
- 한국교통연구원의 **교통폴리곤**
- KT 휴대폰 **LTE + 5G 시그널 데이터**

담고 있는 정보: 출발/도착지, 시간대, 이동인원, 이동자 성/연령, 이동 소요시간, 이동 거리

### 1.6 이동인원의 의미
- KT LTE/5G 사용자 신호를 바탕으로, KT 시장점유율 등 여러 보정을 거쳐 **전체 인구 이동으로 확장 보정한 추정치**
- 즉 KT 고객 수가 아니라 실제 두 지역 간 이동량을 추정한 숫자

### 1.7 하루 평균 생활이동량
| 기간 | 하루 평균 서울을 오가는 이동량 |
|---|---|
| 2019.11 ~ 2019.12 | 2,275만 |
| 2020.01 ~ 2021.07 | 1,867만 |
| 2021.08 ~ | (미표기, "?") |

- 분석기간 2019.11 ~ 2021.07 (21개월), 총 이동 약 122억 건
- 대중교통, 승용차, 자전거, 도보 등 **수단 구분 없이 포함**
- **제외**: 자녀 등하교 동행, 동네 산책 등 특정 지점 체류시간이 짧은 이동, 매우 가까운 근거리 이동

### 1.8 용어 정리 (표 1-1)
| 용어 | 개념 |
|---|---|
| 야간상주지 (H) | 거주지로 추정되는 곳. 당월 기준 특정 지역에서 **새벽 5시를 포함하여** 체류한 누적시간이 많은 곳 |
| 주간상주지 (W) | 근무지 또는 학교로 추정되는 곳. 당월 기준 특정 지역에서 새벽 5시 이후 체류를 시작해 이튿날 새벽 5시 이전까지 체류한 누적시간이 많은 곳 |
| 기타지역 (E) | 야간상주지와 주간상주지가 아닌 지역 |
| 출발시간 | 집계된 이동의 출발시간 (빅데이터캠퍼스: 20분 단위 / 열린데이터광장: 1시간 단위) |
| 도착시간 | 집계된 이동의 도착시간 (빅데이터캠퍼스: 20분 단위 / 열린데이터광장: 1시간 단위) |
| 출발지 | 빅데이터캠퍼스: 교통폴리곤 / 열린데이터광장: 행정동 또는 자치구 |
| 도착지 | 빅데이터캠퍼스: 교통폴리곤 / 열린데이터광장: 행정동 또는 자치구 |
| 성 | 가입자의 성별코드 |
| 연령 | 가입자의 연령코드 |
| 이동시간 | 집계된 이동에 대한 평균 이동 시간 |
| 이동인원 | 집계된 가입자수를 전국 성연령별 인구로 보정한 이동 인원수 |

## 2. 작성 세부절차 및 방법

### 2.1 KT LTE/5G 시그널 데이터 특성
- 휴대폰 단말과 기지국 간 통신 이력. 통화/문자 기반보다 발생량이 매우 많고, 개인 간 차이가 적으며 고르게 발생
- 기지국 간 이동 시 **사용 여부와 무관하게** 자동으로 신호 적재 → 위치·동선 파악에 유리

| 구분 | 발생 시점 | 발생량 | 비고 |
|---|---|---|---|
| LTE/5G 시그널 | 기지국 변경, 데이터 사용 등 (평균 5분 간격) | 1인 평균 8,640건/월 | 사용 유무와 관계없이 레코드 발생 |
| 콜데이터(3G) 통화/문자 | 통화 착/발신, 문자 수/발신 | 1인 평균 120건/월 | 미사용 시 레코드 없음 |

→ 약 70배 차이. 통화/문자 기반은 개인차 큼, 발생 간격 불규칙, 야간 신호 축소 문제가 있음.

### 2.2 작성 4단계 파이프라인
1. 휴대폰 로그에서 **이동과 체류 구분**
2. **야간상주지/주간상주지 추정**하여 체류지 구분
3. **전수화 보정계수** 적용
4. 기지국 단위 이동을 **집계 공간 단위로 산출**

#### 1단계: 이동과 체류 구분
- 휴대폰이 특정 기지국에 물려 있는 정보로 대략적 위치와 상태 추정
- 원시 데이터 노이즈:
  - **핑퐁 핸드오버**: 신호가 2~4개 기지국을 진동하듯 탈부착
  - **원거리 기지국 순간 부착**: 자석처럼 먼 기지국에 잠깐 붙었다 떨어짐
- 사람의 일반적인 이동 속도·특성을 고려해 노이즈 처리 후 체류/이동 구분
- 기지국 체류 시간 기반으로 체류만 남겨 **체류지별 로그**로 정리 → **체류지와 체류지 사이 움직임 = '이동'**

#### 2단계: 야간/주간 상주지 추정
- 새벽 5시 정각 기준으로 판별
- 절차:
  1. 하루 시간대를 05시 기준으로 재편: `00~24시 → 05~29시` 단순 변환
     - `체류 시작시간 < 체류 종료시간` → 해당 기지국 **주간상주지 점수 증가**
     - `체류 종료시간 < 체류 시작시간` → 해당 기지국 **야간상주지 점수 증가**
  2. 기지국별 체류시간 계산 후 우선순위에 따라 H/W 추정
- 전체 체류지를 H / W / E 로 구분
- 이동 성격 구분:

| 출발 → 도착 | 이동 성격 |
|---|---|
| H → W | 출근/등교 |
| W → H | 퇴근/하교 |
| E → (H/W/E), (H/W) → E | 기타 이동 |

- 단순 인원수가 아니라 **이동 성격까지 추정해서 개방**. 반복적 이동(생활이동인구)과 비정기적 이동 구분 가능

#### 3단계: 전수화 보정 (야간상주지 기준 4단계)
1. **KT MS 보정계수**: KT 휴대폰 시장점유율의 역수
2. **LTE+5G 가입률 보정계수** (행정동 × 성 × 연령): KT 내 휴대폰 가입자 중 LTE+5G 비중
3. **휴대폰 On 비율 보정계수**: 휴대폰 OFF, 기기결함, 기지국 통신결함 등 포함
4. **성 × 연령 추가보정**: 1~3단계 후 전국 KT 고객 수와 전국 주민등록인구 비교

한계:
- KT 고객 1명의 이동이 몇 배로 증가됨. **10세 미만, 80세 이상** 등 휴대폰 사용률 낮은 연령대는 1명이 **10배 가까이** 보정되기도 함 → 연령별 해석 시 주의
- KT 고객이 한 명도 이동하지 않은 OD는 보정 후에도 **0**. 실제로는 타사 사용자나 휴대폰 미사용자의 이동이 있을 수 있음

#### 4단계: 공간 집계
- 기지국 단위 개별 이동을 **교통폴리곤** 등 공간 집계단위로 산출
- **소요시간**: 한 달 단위로 출발지·도착지별, 기타 기준(주중/주말 등)에 따라 이동시간 전부 수집 → 상위/하위 이상치 제거 → 평균
  - 한 달 정도의 충분한 샘플이 있어야 신뢰성 있는 소요시간이 나왔기 때문
- 출발도착지, 시간대, 연령별, 통행유형별로 구분 집계
- **출발지 또는 도착지에 서울이 포함된 이동만** 필터링해 개방

공간 위계: `교통폴리곤 < 행정동 < 자치구 < 서울 및 기타 시도 < 전국`

- 교통폴리곤: 전국 **18,884개**, 서울 **1,831개**
  - 집계구를 병합해 한국교통연구원이 개발. 폴리곤 하나에 다수 기지국 포함
  - 교통폴리곤들을 결합하면 행정동 경계와 **완전히 일치**
  - 2019년 기준 서울 행정동 424개 → 행정동 1개 ≈ 교통폴리곤 4~5개
- 기지국 분포: 전파누리(https://spectrummap.kr)에 공공데이터로 개방

## 3. 데이터 공개

### 3.1 공개 방법
- 서울 열린데이터광장(data.seoul.go.kr) 메뉴: `통계 → 서울 생활이동`
- 서울시 빅데이터캠퍼스 (방문자 대상)
- **월 단위 공개, 기준월 익월 20일**

### 3.2 열린데이터광장 버전
| 항목 | 내용 |
|---|---|
| 공간 단위 | 행정동 / 자치구 |
| 시간 단위 | **도착시간 기준 1시간** (예: 14시 도착 = 14~15시 중 도착) |
| 집계 기준 | 월 단위로 각 요일의 이동인구 합산 |
| 작성 주기 | 월 단위 일괄 공개 |

스키마 (표 3-1, 행정동 예시):

| 대상연월 | 요일 | 도착시간 | 출발 행정동 | 도착 행정동 | 성별 | 나이 | 이동유형 | 평균이동시간 | 이동인구 |
|---|---|---|---|---|---|---|---|---|---|
| 202110 | 월 | 9 | 1121062 | 1121058 | F | 0 | HW | 10 | 111.18 |
| 202110 | 월 | 0 | 1119076 | 1114074 | M | 20 | EE | 40 | * |
| 202110 | 일 | 14 | 1122052 | 1122052 | F | 60 | EH | 10 | 11.37 |

첫 행 해석: 2021년 10월 월요일에 1121062(관악구 인헌동)에서 1121058(관악구 낙성대동)로 이동해 9~10시 사이 도착, H→W 이동한 0~9세 여성 총 111.18명, 평균 이동시간 10분.

컬럼 규칙:
- 행정동/자치구: **통계청 기준** 행정동/자치구 코드
- 성별: F(여성), M(남성)
- 나이: 10~79세는 5세 단위, 그 외 0~10세, 80세 이상으로 구분 (값은 구간 시작값, 예: 20 = 20~24세)
- 이동유형: H(야간상주지), W(주간상주지), E(기타)의 출발-도착 조합 (HW, EE, EH 등)
- 평균이동시간: 동일 열 내 이동인구의 월 단위 평균 이동시간 (**10분 단위**)
- 이동인구: 추정값이라 소수점 표출. 개인정보 비식별화를 위해 **3명 미만은 `*` 처리**

첫 행 해석: 2021년 10월 23일 111493(서초구 양재1동)에서 110060(중구 소공동)으로 14:40~15:00 출발, 16:00~16:20 도착, H→E 이동한 30~34세 남성 총 9.74명. 평균 이동시간 79분, 평균 이동거리 11,886m.

컬럼 규칙:

- 소요시간: 월 단위 평균 이동시간 (**1분 단위**)
- 이동거리: 월 단위 평균 이동거리 (**m 단위**)
- 인원: 추정값, 소수점 표출, 3명 미만 `*`

### 3.4 두 버전 비교 요약
| | 열린데이터광장 | 빅데이터캠퍼스 |

### 4.5 공간 분석 예시
- **출근 소요시간 등시선**: 종로1·2·3·4가동/사직동/소공동/명동, 강남역~역삼역 주변으로 8~10시 도착하는 출근자의 출발 행정동별 평균 소요시간 (10분 간격 등시선)
- **사회초년생(20~24세) 통근통학지역 순위** (2019.10): 주요 대학 인근과 종로·강남 업무지역이 상위 (신촌동, 역삼1동, 종로1·2·3·4가동, 서교동, 여의동, 화양동, 안암동 등)
- **주말 출근/등교 장소 순위** (서비스업 종사자로 추정): 역삼1동 6,123, 종로1·2·3·4가동 5,142, 신촌동 4,965, 서교동 4,886, 여의동 4,085, 삼성1동 3,006 등
- **심야(22~03시) 퇴근/하교 경로** (일평균 100명 이상): 1위 서대문구 신촌동 → 연희동 737, 동작구 흑석동 → 상도1동 362, 관악구 대학동 → 낙성대동 353 등. 근거리 교통망, 가로등, 안전정책 연계 가능
- **퇴근 후 들르는 곳** (18~21시, 직장/학교 → 집 아닌 곳, 평일 100명 이상): 1위 중구 명동 → 종로1·2·3·4가동 570, 서초2동 → 역삼1동 500, 소공동 → 종로1·2·3·4가동 482 등. 종로·강남역·홍대 중심
- **서울 외부 거주 통근통학자** (일평균, 읍면동 기준): 남양주 별내동 7,719, 하남 미사2동 6,554, 남양주 와부읍 6,217, 하남 미사1동 5,867, 남양주 화도읍 5,714, 의정부 호원1동 5,046 등. 주요 도착지는 광화문, 여의도, 강남역, 가산디지털단지, 문정동 일대
- **근거리 이동**: 1km 이하 이동은 점심(11~13시) 피크가 가장 큼. 밀집지(광화문, 홍대, 여의도, 강남역, 잠실역 등) → 보행로 개선, 상권 형성
- **2~3km 이동 밀집지**: 구파발역, 노원역, 디지털미디어시티, 발산역, 오목교역, 여의도, 고속터미널, 코엑스, 문정역, 미사강변, 서울대 등 → 근거리 교통수단 검토
- **접근 취약 지역 도출**: 여의도역 인근으로 이동하는 사람들의 직선거리 기준 시속 계산 (2018.06). 직선거리는 가깝지만 교통수단 연결이 나쁜 지역 발견 (남북방향 접근성 낮음)

## 5. 사용 시 주의사항 (매뉴얼에서 언급된 것)
1. 이동인원은 **KT 데이터 기반 추정치**. 실제 카운트가 아님
2. 10세 미만, 80세 이상은 보정 배율이 커서(최대 10배 가까이) 신뢰도 낮음
3. KT 고객 이동이 0인 OD는 0으로 나옴 (실제 이동이 있어도)
4. 짧은 체류 이동, 매우 가까운 근거리 이동은 제외됨
5. 이동수단 구분 없음 (대중교통/승용차/도보 섞여 있음)
6. 출발지 또는 도착지에 서울이 포함된 이동만 개방
7. 3명 미만은 `*` 처리 → 파싱 시 결측 처리 필요
8. 열린데이터광장은 통계청 행정동 코드, 빅데이터캠퍼스는 교통폴리곤 코드 → 조인 키가 다름
9. 열린데이터광장 버전은 개별 날짜가 아닌 월 × 요일 합산
