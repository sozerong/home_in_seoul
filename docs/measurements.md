## 측정 4. 전월세 지번 → 필지 고유번호(PNU) → 상가정보 좌표 (결정 5 사전 시험)
- 목적: 전월세의 (시군구 코드, 법정동 이름, 지번)으로 필지 고유번호를 만들 수 있는지, 그리고 이미 받은 상가정보 좌표만으로 얼마나 덮이는지 본다.
- 조건: 상가정보 서울 202606(554,092행)의 지번코드 구조 확인, 법정동 이름 → 법정동 코드 대응은 상가정보의 (시군구코드, 법정동명, 법정동코드)에서 만듦. 전월세는 2026-10-21 손 수집 강남구 오피스텔·연립다세대 202609·202610 파일 4개의 고유 (시군구, 법정동, 지번) 607개. 대지구분은 1(대지)로 가정. 1회 실행, Python 3.12.8.
- 결과:
  - 상가정보 지번코드 = 법정동코드(10) + 대지구분코드(1) + 본번(4자리) + 부번(4자리)인 행이 554,069 / 554,092. 지번코드는 **필지 고유번호(PNU) 19자리 구조**다.
  - 전월세 607개 모두 법정동 이름을 코드로 바꿀 수 있었고, 607개 모두 PNU를 만들 수 있었다.
  - 그 PNU가 상가정보에 있는 것은 **199 / 607 (33%)**. 상가가 없는 건물이 많아 상가정보만으로는 부족하다.
- 남은 것: 모든 필지(또는 건물)를 PNU와 좌표로 담은 공공 파일이 필요하다.
- 이어서 (2026-10-21): 연속지적도 서울(LSMD_CONT_LDREG_11_202610, 896,692 필지)과 대조하니 같은 607개 PNU가 **607 / 607 (100%)** 있었다. 대지구분을 1로 가정한 PNU만으로 모두 찾았다.

## 측정 5. 생활이동 한 달치 집계: Python, DuckDB, Spark (단계 8)
- 목적: Spark가 필요한 규모인지 본다(설계 원칙 5). 같은 집계를 세 도구로 돌려 시간과 메모리를 비교한다.
- 입력: 생활이동_행정동_202607.zip을 푼 CSV 24개(시간대별), 6,271,856,922 B, 141,178,148행. 압축 해제 14.7초(1회, 측정에서 뺌).
- 집계: (도착 행정동, 시간대, 이동유형)별 행 수, 이동인구 합, 이동인구 × 이동 시간 합. 결과 235,734그룹. 웨어하우스에서 쓰는 집계와 같은 모양(그룹 기준만 다름).
- 방법: `measure/stage8_compare.py`. 도구마다 새 Python 프로세스로 한 번씩 돌리고, 시간은 프로세스 시작부터 끝까지(Spark는 JVM 시작 포함), 메모리는 자식 프로세스(Spark의 java)까지 합친 최대 RSS를 0.2초마다 잰 값.
- 환경: Ryzen 7 7800X3D(논리 코어 16), RAM 63GB, Windows 11, Python 3.12.8, DuckDB 2.0.0, PySpark 3.5.9(Java 1.8.0_202, `local[*]`, driver memory 8g). 2026-10-21~22 측정.

- **DuckDB는 23행 적게 셌다.** 형식 감지가 실패해 `ignore_errors=true`로 읽었는데, 그 옵션이 23행을 조용히 버린 것으로 본다(어느 행인지는 [확인 필요]). Python과 Spark는 같은 행 수다. 파이프라인에 DuckDB를 쓴다면 이 옵션은 쓰면 안 된다(설계 원칙 4).
- Spark를 Windows에서 돌리며 겪은 것: `C:\hadoop\bin`에 `hadoop.dll`이 없어 `*.csv` 경로 펼치기에서 JVM이 죽었고(파일 목록을 직접 넘겨 피함), 종료 시 안내문이 표준 출력에 섞였다. 처음 측정은 오류를 버리게 짜여 있어 35분 동안 멈춘 채로 보였다(이후 오류를 보이고 1시간 제한을 둠).
- 결과: 한 달치 6.3GB는 단일 PC에서 DuckDB가 Spark보다 약 5배 빠르고 메모리는 약 6분의 1이다. 이 규모에서는 Spark의 분산 처리 이점이 나타나지 않았다. 현재 파이프라인(Python 한 줄씩 → PostgreSQL)은 한 달치를 약 2분 20초에 집계하며, 월 1회 실행이라 병목이 아니다.
- 재지 않은 것: CLAUDE.md 단계 8의 "버스 시간대별 1년치"는 승인된 질문의 어떤 지표에도 버스를 쓰지 않아 수집 스크립트를 만들지 않았으므로(결정 6) 재지 않았다. 단계 1 탐색 파일 크기는 data_sources.md 7절.
