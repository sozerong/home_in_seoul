## 측정 2. 생활이동 행정동 한 시간대 파일 전체 읽기 (탐색용, 참고값)
- 목적: 단계 8 Spark 필요성 판단 전에, 표준 라이브러리만으로 한 파일을 끝까지 읽는 데 드는 시간의 감을 잡는다. DuckDB/Spark 비교 측정이 아니다.
- 조건: 생활이동_행정동_202607.zip 안의 생활이동_행정동_2026.07_08시.csv(압축 해제 300,897,982 B, zip 안 압축 크기 51,834,791 B), 6,734,514행. zip에서 압축을 풀지 않고 스트리밍으로 읽음. Python 3.12.8 표준 라이브러리 csv 모듈, 한 행씩 컬럼별 값 분포를 세는 집계. 1회 실행.
- 환경: Ryzen 7 7800X3D, RAM 63GB, Windows 11
- 결과: 실제 경과 시간 28.7초 (bash `time`의 real 값, 1회). 반복 측정을 하지 않았으므로 편차는 모른다.
- 남은 것: 한 달(24개 파일) 전체와 DuckDB, Spark 비교는 단계 8에서 같은 집계로 잰다.

## 측정 3. 생활이동 출근 구간의 데이터 충분성 (직장 = 역삼1동)
- 목적: 질문 2-4(출퇴근 시간 계산)에서 나이대를 좁혀도 값이 남는지 확인한다.
- 조건: 생활이동_행정동_202607.zip의 07시, 08시, 09시 파일. 도착 행정동 1123064(역삼1동, 2021 코드), 이동유형 HW, 요일 월~금. 서울 출발은 11로 시작하는 7자리 코드. 1회 실행, Python 3.12.8 표준 라이브러리, 실행 시간 15.2초(real).
- 환경: Ryzen 7 7800X3D, RAM 63GB, Windows 11
