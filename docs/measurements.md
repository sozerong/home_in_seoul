## 측정 4. 전월세 지번 → 필지 고유번호(PNU) → 상가정보 좌표 (결정 5 사전 시험)
- 목적: 전월세의 (시군구 코드, 법정동 이름, 지번)으로 필지 고유번호를 만들 수 있는지, 그리고 이미 받은 상가정보 좌표만으로 얼마나 덮이는지 본다.
- 조건: 상가정보 서울 202606(554,092행)의 지번코드 구조 확인, 법정동 이름 → 법정동 코드 대응은 상가정보의 (시군구코드, 법정동명, 법정동코드)에서 만듦. 전월세는 2026-10-21 손 수집 강남구 오피스텔·연립다세대 202609·202610 파일 4개의 고유 (시군구, 법정동, 지번) 607개. 대지구분은 1(대지)로 가정. 1회 실행, Python 3.12.8.
- 결과:
  - 상가정보 지번코드 = 법정동코드(10) + 대지구분코드(1) + 본번(4자리) + 부번(4자리)인 행이 554,069 / 554,092. 지번코드는 **필지 고유번호(PNU) 19자리 구조**다.
  - 전월세 607개 모두 법정동 이름을 코드로 바꿀 수 있었고, 607개 모두 PNU를 만들 수 있었다.
  - 그 PNU가 상가정보에 있는 것은 **199 / 607 (33%)**. 상가가 없는 건물이 많아 상가정보만으로는 부족하다.
- 남은 것: 모든 필지(또는 건물)를 PNU와 좌표로 담은 공공 파일이 필요하다.
- 이어서 (2026-10-21): 연속지적도 서울(LSMD_CONT_LDREG_11_202610, 896,692 필지)과 대조하니 같은 607개 PNU가 **607 / 607 (100%)** 있었다. 대지구분을 1로 가정한 PNU만으로 모두 찾았다.
